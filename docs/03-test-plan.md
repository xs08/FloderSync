# FloderSync 功能测试方案（草案）

状态：MVP 测试基线已确认（2026-09-02）

## 1. 测试原则

- 先定义行为与安全不变量，再实现功能。
- Git 集成测试只使用临时目录和本地 bare remote，不依赖公网或真实账号。
- 时间、文件事件、进程执行、通知和存储均通过协议替换，保证测试确定性。
- 高风险场景优先：冲突、认证失败、进程中断、重复触发、路径失效、配置损坏。

## 2. 测试层级

### 单元测试

- `SyncStateMachine` 的所有合法/非法状态迁移。
- 时间点、间隔、星期与睡眠补偿的调度计算。
- 触发去重、运行中合并与全局并发限制。
- Git 状态解析、退出码到领域错误的映射。
- 自动提交信息模板与日志脱敏。
- 配置校验、schema 迁移与损坏恢复。

### 组件测试

- 使用 fake `GitClient` 验证同步步骤顺序、跳过逻辑、取消和超时。
- 使用 fake clock/event stream 验证调度器和 FSEvents 去抖。
- 使用临时 Application Support 目录验证原子写入与备份恢复。
- 验证菜单栏 view model 和设置 view model 的所有状态投影。

### Git 集成测试

测试夹具：两个临时工作区 + 一个本地 bare remote。

- 无变化：不创建空提交，结果为成功/无需同步。
- 只有本地变化：提交并推送。
- 只有远端变化：拉取并更新本地。
- 两端无冲突变化：rebase 后推送。
- 两端冲突：停止、保留现场、标记 `needsUserAction`。
- 未配置 remote、detached HEAD、无 upstream、无作者信息。
- Git 进程非零退出、超时、取消、输出含敏感 URL。
- 文件名包含空格、Unicode、换行或以短横线开头。
- Git LFS/submodule 的实际边界在需求确认后补充。

### macOS 系统集成测试

- 菜单栏图标与 window-style 弹窗打开/关闭。
- `SMAppService` 注册、拒绝、取消注册以及系统设置状态变化。
- 睡眠/唤醒、网络离线/恢复、目录移动或外接磁盘断开。
- 系统 Git、Homebrew Git 和自定义路径发现。
- HTTPS Keychain 与 SSH Keychain 的非交互认证；自定义 ssh-agent 行为单独记录。
- 浅色/深色、增大对比度、减少透明度、减少动态效果。

### UI 与可访问性测试

- 菜单栏全局状态、单仓库状态和快捷同步操作。
- 设置页新增、编辑、禁用、移除（确认只移除配置）。
- 空状态、同步中、失败、冲突、路径无权限、Git 不可用。
- 完整键盘导航、VoiceOver 标签、焦点顺序、可点击区域与状态非颜色依赖。
- 窗口在支持的最小尺寸下无截断，长仓库名与中英文文案可读。
- 在英文和简体中文系统语言下运行关键 UI 流程，验证无硬编码文案、缺失 key 或布局溢出。
- 自动校验每个 String Catalog key 都同时包含非空英文和简体中文翻译。
- 验证一级侧边栏、仓库模块内任务增删、底部通用/退出以及菜单栏快速添加仓库。
- 验证侧边栏固定宽度且无折叠入口，仓库为空时不生成第二层列表。
- 验证跟随系统/英文/简体中文切换立即刷新且重启后保留。
- 验证添加仓库预检能区分已同步和未同步状态，未同步时仅在用户确认后执行同步。
- 验证冲突、pull/push 失败会同时投影到菜单栏图标、菜单仓库行和设置仓库列表，并包含人工处理提示。
- 验证设置窗口不显示标题文字，原生窗口控制按钮仍可用，外层与侧边栏连续圆角在浅色/深色下无裁切。
- 验证侧边栏导航选中态、最小窗口尺寸及长中英文标题无溢出；底部通用/退出为图标按钮且具备 tooltip 与无障碍标签。
- 验证设置窗口无原生标题栏占位，内容标题不被窗口控制区域遮挡。
- 验证鼠标与 Tab 导航只产生一个蓝色填充选中态，不残留系统焦点边框。
- 验证跟随系统、浅色、深色主题即时切换并持久化，菜单栏和设置窗口保持一致。
- 验证设置窗口在挂载 SwiftUI 内容前已经包含 `.fullSizeContentView`、透明 titlebar、空 toolbar 与透明窗口背景，并仍保留三个标准窗口按钮。
- 验证从深色切换到浅色时顶部区域和内容在同一渲染周期更新，不出现独立白色标题栏首帧。
- 验证 Asset Catalog 可加载 `MenuBarIcon`，资源采用 original rendering 且尺寸有效；人工确认图标视觉占位接近 1:1，16–18pt 下细线文件夹、双向轨道箭头和蓝青渐变仍可辨识。
- 验证英文与简体中文 README 都能显示品牌 PNG，顶部语言链接可互相跳转，安装、构建、认证和数据路径信息保持一致。

## 3. P0 验收矩阵

| 功能 | 成功路径 | 关键失败路径 | 不变量 |
| --- | --- | --- | --- |
| 手动同步 | 单仓库/全部完成 | 冲突、认证失败 | 不丢文件、不强推 |
| 定时同步 | 准点触发 | 睡眠、应用重启 | 不重复风暴 |
| 间隔同步 | 完成后重新计时 | 单次运行超时 | 同仓库不并发 |
| 文件变化 | 去抖后同步 | `.git` 自触发、大量事件 | 无变化不提交 |
| 登录启动 | 状态一致 | 用户拒绝/系统禁用 | UI 不谎报启用 |
| 配置存储 | 重启后恢复 | 文件损坏/旧 schema | 可恢复、无凭据 |
| 历史诊断 | 结果可追踪 | 输出含 secret | 日志已脱敏 |

## 4. 发布前质量门

- P0 用例全部通过，P1 无阻断缺陷。
- 真实 SSH 和 HTTPS 认证矩阵至少各通过一种标准配置。
- 100 次事件风暴压力测试不产生同仓库并行执行。
- 冲突、断网和强制退出演练未发现工作区数据丢失。
- Instruments 检查空闲 CPU、内存增长和文件监听资源释放。
- 签名、公证、首次启动、登录启动、升级和卸载路径验证完成。
